- Background runs now record `cancelled` when you stop them and `interrupted` when n00n exits, instead of `succeeded`. Streaming output no longer writes one run-store update per token.
- n00n starts when the background run store cannot open. Background runs are turned off, and a startup warning explains why. Print and SDK modes no longer open the store.
- The live TUI bridge uses `agent.session_roundtrip_timeout_secs` again.
- Background `run_task` returns `agent_id`, so `get_agent` and `control_agent` can reach the child session.
- Parent sessions keep acknowledging background run results after 1,024 deliveries. Shrinking an oversized session record keeps the delivery ledger.
- Reaping a session tree works in any order, and it no longer orphans saved child sessions.
- A failed auto-compaction no longer ends a turn when the context still fits the model window.
- Interpreter frames over the size limit no longer drop the next request or fill memory.
