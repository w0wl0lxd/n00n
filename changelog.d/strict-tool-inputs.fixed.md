Built-in `batch`, `edit`, `multiedit`, `edit_lines`, `insert_lines`, `grep`, `bash`, `read`, `write`, `code_execution`, `webfetch`, `websearch`, `glob`, `index`, `todo_write`, `view_image`, `fusion`, and `semblem` schemas now reject unknown properties with `additionalProperties: false` and enable `strict` where the schema has no open objects. Optional fields use nullable types, so invalid keys like `command`, `tool_uses`, or `recipient_name` are caught before dispatch. The tool `strict` flag is now wired through to providers that support grammar-constrained tool calls.
