Question prompts and long-running tools no longer block the UI during periodic saves or shutdown. Interactive prompts no longer compete with running tools for execution capacity, busy agent scopes no longer reserve slots needed by other sessions, and ambiguous provider failures replay once without pausing for approval when no output reached the client. Lua subprocesses now use bounded output buffering, lower CPU priority, process-group cancellation, and Linux memory limits, while excessive `async.run` fanout is rejected before it can grow an unbounded task backlog.
