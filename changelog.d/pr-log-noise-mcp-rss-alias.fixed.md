Stopped spurious warnings during normal operation: an MCP server that dies while still connecting no longer logs a false "not running" warning, a job's RSS monitor no longer stops permanently when a child process exits mid-check, several built-in plugins no longer dispatch through deprecated tool aliases, and a failed background MCP OAuth attempt now backs off instead of retrying immediately. A server that dies during its handshake is now reported as a failed start rather than registered as running with its tools advertised, and several open sessions seeing the same unauthenticated server now make one background OAuth attempt between them instead of one each.
