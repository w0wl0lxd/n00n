# n00n Constitution

## Core Principles

### Token-Efficient Exploration

Prefer `codegraph`, `arbor`, `semblem`, `index`, and `rtk` over broad greps and raw shell output; compress before context. Use `explore` as the primary entry point for codebase questions, routing to the appropriate structural backend. Filter and pipeline with `code_execution` to reduce context usage.

### TDD / Red-Green-Refactor

Failing test first, then minimum implementation, then refactor. Unit tests in `#[cfg(test)]` modules. Use `#[test_case]` and snake_case test names. No bullshit tests (tautologies), no flaky tests (no weird sleeps). In tests, const error/status messages and assert against shared constants.

### Safety & No Silent Failures

`unsafe_code = "forbid"` workspace-wide. No `.ok()` discards, no silent-default patterns. Library crates use `thiserror` for domain-specific errors; binary edges use `color-eyre`. Missing data, parse failures, dependency errors, closed channels, and invalid state must become typed errors or explicit sanitized logged rejection.

### No AI Attribution

No `Generated by Devin`, no `Co-Authored-By: bot`, no attribution in commits, PRs, changelogs, or any authored content. Author all commits and PRs as the human user using the Git identity configured in `~/.gitconfig`.

### Worktree + Ship Discipline

Non-trivial work in a git worktree on a new branch. Finish by committing with a clear Conventional Commit message, pushing the branch, and opening a draft PR. Do not force-push, push to main/master, or merge without explicit confirmation.

### Dependency Discipline

Add new dependencies to workspace `Cargo.toml` first, then `workspace = true` in the crate. Prefer versions older than 7 days. No floating ranges (`latest`, `*`, unbounded `>=`). Run `cargo deny check` before adding. Disable default features when they pull unused networking, TLS, compression, native, proc-macro, or runtime surface.

## Quality Gates

- `cargo clippy --all --tests -- -D warnings`
- `cargo nextest run --workspace`
- `cargo deny check`
- `cargo fmt --all`

## Governance

This constitution is the speckit workflow source of truth. n00n behavior is further constrained by `AGENTS.md`. Amendments require PR review.
